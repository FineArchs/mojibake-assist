# Mojibake Lab

Vue 3 / TypeScript / Vite による文字化け解読補助ツール。

## 起動

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

```sh
npm run build
npm run preview
npm test
```

## 同期の仕様

- 共通のバイト列をShift-JIS（ブラウザのWindows-31J互換デコーダ）、16進数、UTF-8として表示します。
- テキスト欄の編集時に、その欄の文字コードで共通バイト列を再生成します。Shift-JISにない文字は `?` になります。
- 不正なバイトの表示には置換文字などを使います。欄を編集するまでは元バイトを保持します。復元不能な表示を編集すると、表示中の文字を再エンコードするため元バイトは変わります。
- 選択範囲は0始まりのバイト位置で同期します。文字境界にない範囲は各欄の文字境界に丸めます。絵文字はUTF-16のサロゲートペアとして扱います。
- 奇数桁・不正な16進入力は入力途中として保持し、正しいバイト列になるまで他欄は最後の確定値を表示します。
- IME変換中は確定を待って同期します。
- 入力内容はブラウザ内だけで処理し、サーバーへの送信や永続保存は行いません。
